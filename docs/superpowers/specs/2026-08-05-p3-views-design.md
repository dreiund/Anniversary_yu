## 一、范围

**本轮做**：
1. 足迹页顶部三段切换补全：列表（已有）＋ **日历** ＋ **地图**
2. **地点档案页**（多入口：地图抽屉、记忆详情小地图卡）
3. 见面详情第三段 **路线图**
4. 选点归并（50 米同店提示 + 选点地图显旧钉）与**地点分类**（选点表单 + 档案页可改）
5. `PlaceCategory` 枚举定死并锁 raw

**不做（明确出界）**：
- 经期浅红底叠加（P5 有数据后加；日历格留 4pt 底色接口位）
- 存量重复地点的合并工具（归并只拦新建；已存在的重复地点不处理）
- MKDirections 真实路线（已决策废弃，见 §八）
- 计划中（planned）见面上日历带（只画已开始/已结束的见面；期待感表达留 P6 评估）

## 二、PlaceCategory（锁死，禁止改序/插入）

```swift
enum PlaceCategory: Int16, CaseIterable {
    case other = 0        // 其他（存量 categoryRaw=0 自动归此类）
    case food = 1         // 美食
    case cafe = 2         // 咖啡甜品
    case scenery = 3      // 景点公园
    case shopping = 4     // 逛街
    case show = 5         // 影展演出
    case stay = 6         // 住宿
}
```

- `label`：其他 / 美食 / 咖啡甜品 / 景点公园 / 逛街 / 影展演出 / 住宿（chips、档案、抽屉共用，无 emoji）
- raw 值进 schema 锁死测试（`ModelSchemaTests` 加用例）；`categoryRaw` 自此解禁写入
- 写入口仅两处：选点表单分类 chips（默认其他；**关联既有地点时隐藏该行**，沿用旧分类）；地点档案类别 chip 点击 → 七类选择 sheet

## 三、日历页（足迹第二段）

### 3.1 月历骨架（两种模式共用）
- 标题「2026 年 8 月」；左右滑动切月；不在当月时导航栏右侧出「今天」小按钮，点击回当月
- 周一起始；非当月格灰字；**今天 = 蓝环数字**（DS.actionBlue 1.5pt 描边圆）
- **见面带**：已开始/已结束见面的日期区间铺淡蓝底（#EDF4FC），首格左上角小蓝字「第 n 次」；进行中见面带铺到今天；跨月见面带延伸至月界，「第 n 次」标注出现在每个月内该带的首格
- **心情表情格**（小样 calendar-cell 选 B）：格内日期下方两枚小 emoji（左=我，右=TA，来自 CDDailyMood；单人打卡只显一枚，无人不显）；当天有记忆再加一颗墨点（不按条数堆叠，数量看抽屉）
- 格底部预留 4pt 底色条位（P5 经期浅红用，本轮恒透明）

### 3.2 双投影开关
- 月历上方居中胶囊双段「自然日 ⇄ 约会日」
- **自然日**：记忆按 `happenedAt` 的自然日归格
- **约会日**（小样 dateday-mode 选 B「聚焦模式」）：
  - 记忆按 `moment.day`（CDDay）归格——跨午夜记录移回归属约会日（例：8/17 0:30 的记录显示在 8/16 格）
  - 见面天下沿加小蓝字 **D1 / D2 / D3…**（= 该格在见面内的天序）
  - **非见面日整格压灰**（日期与 emoji 降至 35% 不透明度；今天蓝环保留）
  - 月历下方加墨色小结卡（darkCard 圆角）：`这个月在一起 N 天 · 记了 M 条回忆`（N=当月见面天数，M=当月按约会日归属的记忆数；N=0 时文案改「这个月还没见面 · 下次见面快来了」）
- 心情 emoji **恒按自然日**显示（打卡是自然日概念，不随投影移动）

### 3.3 点某天 → 底部抽屉（小样 day-tap 选 A）
- 半屏 sheet（`presentationDetents [.medium, .large]`），月历留在身后
- 结构：日期头「8 月 15 日」＋蓝字「第 n 次见面 · Dd」（非见面日无蓝字）→ 心情行「{emoji} 我 · {emoji} {TA昵称}」（无人打卡则整行省略）→ 记忆行列表（34pt 缩略图 + 标题 + 类别·时刻 + 我的星分）→ 封盘行「{H:mm} 封盘 · 晚安」（该约会日已封盘时）
- 记忆行点击 → 记忆详情（push）；无任何内容时正文区显示「这天还没有记录」
- 抽屉内容跟随当前投影模式的归日规则

## 四、足迹地图（足迹第三段）

### 4.1 地图与钉
- MapKit 弱化风格（`.standard(pointsOfInterest: .excludingAll)`，隐藏他人 POI）
- 数据源：本 couple 全部**有坐标**（lat/lon 非 0）且**至少关联 1 条记忆**的 CDPlace
- **照片钉**：30pt 圆角矩形（白 2pt 描边 + 投影），图为该地点最新记忆的首张照片；无照片地点用米灰底（parchment）+ 地点名首字墨字（不引入类别配色，守唯一行动蓝纪律）
- **聚合**（视觉重叠即合并，屏幕间距 < 44pt）：墨色（darkCard）圆角小块，文字 **「6 处」**（仅数量，见 §八偏差 3）；点击聚合 = 地图放大一级并居中该簇
- 顶部筛选 chips 横滑一行：全部 + 七类（选中 = 蓝底白字）；筛选同时作用于钉与聚合计数

### 4.2 点钉 → 富抽屉（小样 map-drawer 选 B）
- 底部圆角卡（非全宽 sheet，左右留 8pt），结构：
  - 头行：40pt 圆照片头 + 名字 + 类别描边 chip + 次行「{地址} · 来过 n 次 · 上次 M/d」（来过口径见 §五）+ 右侧蓝字「档案 ›」
  - 均分行：两枚灰底小卡「我的均分 4.5」/「{TA昵称}的均分 5.0」+ 墨条（满分 5 映射条宽）；无评价显示「—」
  - 照片条：最近 3 张记忆缩略 + 「+n」
- 点抽屉任意区域或「档案 ›」→ 地点档案；点地图空白处收抽屉

## 五、地点档案页（push 页；入口：地图抽屉、记忆详情小地图卡）

- 头部（居中）：64pt 圆照片头（最新照片）→ 名字 + 类别 chip（**点击可改分类**，七类 sheet）→ 地址灰字
- 三格统计卡：来过 n 次 ｜ 我的均分 + 墨条 ｜ {TA昵称}的均分 + 墨条（均分=各自对该地点全部记忆评价的星均值）
- 「在地图中查看 ›」蓝字：跳足迹地图段并居中该点（携带定位参数切段）
- 历史列表**按见面分组**（小样 place-profile 选 A）：组头「第 n 次见面 · yyyy.M.d–d」（点击跳该次见面详情）→ 组内记忆行（缩略图 + 标题 + M/d HH:mm + 右侧两行「我 ★x.x / {TA} ★x.x」）→ 行点击跳记忆详情
- 「来过 n 次」口径 = 关联记忆的**去重约会日数**（同一天两条算一次）

## 六、路线图（见面详情第三段）

- 见面详情顶部 chips 扩为「时间线 / 路线图 / 计划」三段（planned 见面仍整页计划，不变）
- 数据：该见面**有坐标**记忆，按约会日分组、组内按 `happenedAt` 升序
- **编号照片钉**：32pt 照片钉左上角蓝色序号圆标（1、2、3…，按当天访问顺序）
- **虚线弧连**（已决策，不查路）：相邻站点间行动蓝虚线（2pt，dash 5/4），带轻微弧度；当天有效点 < 2 时只显钉不画线
- 顶部天数 chips：「全部 / D1 / D2 / …」（小样 route-page 选 A）；「全部」显示整个见面全部站点（线仍按天分段着色一致，天与天之间**不连线**）；切天时地图自动 fit 该天点集
- 右下角 40pt 蓝色圆形**播放悬浮钮**（SF Symbol play.fill，无文字）：点击后线条按访问顺序逐段生长（每段约 0.5s，swiftui-motion 实装），钉子随线到达弹入；播放中按钮变 stop 可中断
- 空态：该见面无带坐标记忆时整页居中灰字「这次见面还没有带地点的记忆」

## 七、选点归并与分类（PlacePickerSheet 增强）

- **旧地点钉**（决策：选点地图显旧钉）：选点地图上把本 couple 既有地点画成 22pt 小照片钉；**点小钉 = 直接关联该地点**（落 pin 到其坐标、名字与分类沿用、分类 chips 行隐藏、保存回传既有 Place 关联——不新建）
- **分类 chips 行**：确认栏名称输入框下方加横滑七类 chips（默认「其他」）；仅新建地点时显示
- **保存兜底弹窗**：保存时若为新建、且 50 米内存在名字相近（相等或互为包含）的既有地点 → 居中 alert：
  - 标题：`是上次那家「{旧地点名}」吗？`
  - 正文：`50 米内有你们来过的地点，关联后来过几次和评分会记在同一家。`
  - 按钮：`就是这家`（关联既有，丢弃新建）/ `新建地点` / `取消`（留在选点页）
- 记忆表单/编辑沿用 PickedPlace 回传通道，新增「关联既有 Place」结果分支；MomentRepository 关联时**不再新建 CDPlace**

## 八、与主 spec 的偏差记录（均为用户决策）

1. §6② 路线图「行动蓝路径线连接**真实路线**」→ **全部虚线直连**（免 MKDirections：零请求、瞬时、离线可用；混合交通不猜路）
2. §5.2 日历格「两人当日心情**双点**」→ **两枚小 emoji 直读**（小样 B）
3. §6② 聚合块「虹口 · 6」→ **「6 处」仅数量**（省去每簇反查区名的请求与不稳定性）
4. §5.2 「经期浅红底（可关）」→ 本轮留接口不实装（P5 数据就位后叠加）

## 九、边界与错误

- 无坐标记忆（placeText 手输或无地点）不上地图、不进路线图；日历与列表不受影响
- 地图空态：还没有任何带坐标地点时，地图页中央灰字「还没有带地点的记忆」
- 日历空月无特殊处理（格子自然为空）；约会日模式小结卡 N=0 文案见 §3.2
- 抽屉/档案打开期间对象被对方远端删除：沿用 PlanView 模式（onDismiss/守卫退出，不渲染已删对象）
- 反查、定位失败沿用 PlacePickerSheet 既有提示；归并名字相似判定不做拼音/模糊匹配（YAGNI）
- 性能：日历单月数据一次 fetch 投影；地图钉照片用缩略图（沿用时间线缩略管线）；聚合在 onMapCameraChange 节流重算

- 真机清单（随实现计划附）：双投影切换与跨午夜归日、点天抽屉、地图筛选/聚合展开、富抽屉均分、档案改分类、路线播放动画、选点点旧钉直接关联、保存兜底弹窗三分支
