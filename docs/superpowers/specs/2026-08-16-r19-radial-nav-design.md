# R19-③ · 四分之一圆环导航 设计稿(待拍板)

日期:2026-08-16 · 状态:**方案已过目,用户思考中,未开工**。小样:`.superpowers/brainstorm/*/content/redesign-radial-nav.html`(展示服务器超时后可让 Claude 重启恢复)。

## 一、动机

足迹与小本本的段切换(分段器)和二级筛选都在**屏幕顶部**,单手够不着,每次点按费力。把导航搬进**拇指热区**——屏幕下角的四分之一圆环。创意来自用户,以下为定稿细节。

## 二、结构(小本本环,右下角)

三层同心,从外到内:

| 层 | 内容 | 交互 |
|---|---|---|
| 外环(四扇区) | 好事 / 生气 / 喜好 / 待办 | 点扇区=切段并收起 |
| 内圈(四圆点) | 全部 / TA 记的 / 我记的 / 私密箱 | 点圆点=切筛选并收起 |
| 圆心(小扇) | 管理 | 点=进入管理模式 |

- 扇区文字沿弧排(近底的接近竖排、近顶的接近横排);真机若嫌歪,退一档改水平字。
- 选中态:当前段扇区=墨底白字;当前筛选点=行动蓝底白字。其余白底(深色模式对应翻转:选中段 #636366、选中点 #409CFF、面 #2C2C2E、线 #3A3A3C)。

## 三、结构(足迹环,左下角)

足迹无二级筛选,原样搬会空一圈(用户反馈"不够美观")——修正为同体量三层:

| 层 | 内容 | 交互 |
|---|---|---|
| 外环(三扇区) | 地图 / 日历 / 列表(列表贴底) | 点扇区=切段并收起 |
| 内环弧带 | **管理**(整条弧带,占小本本内圈同一半径带) | 仅列表段亮起可点;日历/地图段置灰占位(体形不变不跳动) |
| 圆心(小扇) | ✕ 关闭 | 收起环 |

## 四、方位规则(用户定稿,设计语言核心)

**环长在自己 tab 的那一侧**:底栏「足迹」在左 → 环从左下角展开;「小本本」在右 → 环从右下角展开。按完 tab 拇指顺势同侧就是环,位置本身成为导航语言;同时天然化解左右手偏好(两页各占一边)。

## 五、交互全则

- **收起态**:56pt 圆钮常驻页面下角(足迹左下/小本本右下)、底栏上方,钮面显示当前段名(如「好事」)。
- **展开**:点圆钮 → 环弹开(弹簧动画,扇区从圆心生长),环外内容蒙纱(浅色 55% 白纱+轻模糊/深色 60% 黑纱)。
- **选择**:点扇区/圆点=切换并收起;点管理=进管理模式并收起;点纱罩或 ✕=取消。
- **进阶手势**:按住圆钮**直接拖到目标松手**,一个动作完成选择(拇指划弧,该形态的最优用法)。
- **顶部收益**:分段器+筛选行整体退场;标题右侧留当前位置小字(如「好事 · 全部」);内容区多出约 90pt。
- **可发现性**:首次进入自动弹开一次演示 + 圆钮轻微呼吸动画。

## 六、几何参数(小样实测值,SwiftUI 按比例换算)

以圆心=屏幕角点:外环带 R 210→150;内圈点心距 105(点半径 17)/足迹内环带 R 140→86;圆心扇 R 62(足迹 ✕ 心 R 54);扇区角:小本本 4×22.5°、足迹 3×30°;层间留 10pt 呼吸缝。圆钮直径 56,距底栏 12。

## 七、实现要点(开工时展开成计划)

- 共享组件 `RadialNav`(暂名):方位(左下/右下)/扇区数组/内圈点数组(可空)/内环带(可空)/圆心动作全参数化;SwiftUI `Path` 自绘扇形 + `onTapGesture`/`DragGesture` 命中判定(极坐标换算);弹簧展开动画(实现时按用户既定要求调 swiftui-motion skill)。
- 替换面:LedgerListView 头部(分段器+筛选行退场,R19-① 刚做的 DSSegmented 在这两页退役)、MeetingsView 头部同;标题旁加当前位置小字。
- 管理模式入口迁移:两页「管理」胶囊退场,入环。
- **UI 测试锚点全迁**:现有测试大量 `app.buttons["待办"]/["地图"]/["好事"]` 点顶部分段——环的扇区是自绘 Path,须给每个扇区/圆点挂 `.accessibilityLabel`(沿用同名文案,测试可少改);展开动作要先点圆钮,导航步骤全数适配。这是本轮最大的回归成本。
- 设置项(可后补):「圆环靠左/靠右」镜像开关。

## 八、开放问题(思考清单)

1. 环是否只做小本本先试点,还是两页一起上?(建议:先小本本,用两天顺手再推足迹)
2. 顶部分段器彻底删除,还是保留成"环的备份入口"?(建议:彻底删,双入口会稀释环的肌肉记忆;但删=老习惯一刀切)
3. 扇区斜排文字真机效果待验;备选水平字。
4. 拖拽手势(按住划弧)第一版就做,还是先只做点选?(建议:第一版先点选,拖拽是纯增量)
5. 「回今天」(日历段,R19-② 刚挪到月份行)不进环——环只管段/筛选/管理,页内功能留在页内。
