> 结束后没做成的变灰卡留时间线、进行中可在时间线加待办;修订:行前已勾掉的准备事项不删——开始时一并
> 进时间线顶部「行前已备」划线卡(无评价照片,不转化)。bug1(单钉投影)/bug2(结束卡标题)已随 8a1f912/dc323d2 修复。

## 一、计划表单时刻化(1A)

- `PlanItemFormSheet` 删掉「指定时间」子开关:「指定日期」Toggle 保留,打开后是单行
  `DatePicker("时刻", selection:, displayedComponents: [.date, .hourAndMinute])`——与记忆表单同款。
- 存库仍写 `day` + `time` 两字段(同一时刻值),**零 schema 变更**;关掉开关 = `day=nil, time=nil` 备忘,不变。
- 旧「全天」数据(`day != nil, time == nil`):列表展示与排序照旧(先全天后按时间的规则保留);
  编辑时时刻预填该日 09:00。

## 二、见面开始:计划整体并入回忆流(4A + 补充确认)

- **「计划」chip 只在 planned 状态显示**(`MeetingDetailView` 三段 chips → ongoing/finished 两段);
  开始见面瞬间若停在计划段,自动回时间线段。
- 开始见面时不删任何计划项:**已完成**的(行前就勾掉的准备事项)变时间线顶部「行前已备」组的
  **划线记录卡**——划线文字 + 实心勾圈、灰调,不带评价/照片、不参与转化,只可左滑删;
  **未完成**的变待办卡(§三)。
- R7「结束后进行前计划看临时小地图」的入口随之作废,能力由灰卡承接(见§三)。

## 三、时间线里的待办卡(2B 散插)与灰卡

- 进行中,时间线数据源 = 记忆 + 该见面全部计划项。**已完成**项集中放时间线最顶「行前已备」小组
  (行前准备像序章,时刻多在第一天之前,集中比散插清晰);**未完成**项中有时刻且落在某个已有天的
  自然日内的,按时刻与记忆混排插进那天的卡片流;**时刻在未来(还没那天)或无日期备忘**的,统一放
  时间线末尾「接下来」小组(正序时间线,未来在尾部,天然成立)。
- 待办卡样式:虚线边框 + 左侧空心圆圈 + 事项名 + 时刻·地点小字(方案页 mockup 版式)。
  点圆圈 = 秒转化(§四);点卡片其余区域 = 预填记忆表单(§四);左滑 = 删除计划(带确认,取消提醒)。
- 「接下来」组末尾放轻按钮「＋ 加个待办」→ 打开 1A 表单,挂当前见面(补充确认 Q2;按钮仅进行中显示)。
- 时间线「管理」批量删只针对记忆:管理模式下待办卡/灰卡不出选择圈、不可选。
- **见面结束时**:仍未划掉的计划项数据保留、提醒取消,时间线里显示为**灰卡**:
  灰底、无圆圈、右上角标「没做成 · 下次再来」;位置规则同待办卡(未来时刻的在尾部组)。
  灰卡带有坐标地点时点击弹临时小地图(PlaceMiniMapSheet);左滑可删(删计划数据)。
  结束后的尾部小组标题由「接下来」改为「没做成的计划」,组内只有灰卡、无加待办按钮。

## 四、转化规则(3B 秒转化 + 编辑路径)

两条路终点一致:生成一条与手动记的完全等价的回忆(可编辑可删、进足迹/地图),**计划项即刻删除**
(一条计划只可能生成一条回忆——源头没了,天然防重,零 schema 变更)。

- 字段映射:事项 → 标题;备注 → 正文·共同记事;时刻 → `happenedAt`——**时刻在未来或无时刻时用当下**
  (避免 `dayForRecord` 为未来日期造出「未来已封盘天」);地点 → 有 `place` 直接链接,只有 `placeText`
  时走 `PlaceResolver.resolve(name:)` 与记忆同管线归并;类型按地点类目映射
  (food/cafe→restaurant,scenery→sight,shopping/show→activity,stay→stay,无地点或 other→other);
  作者 = 当前用户。
- **秒转化**(点圆圈):无弹窗,待办卡原位过渡成记忆卡;评价照片以后随时编辑补。
- **编辑路径**(点卡片):打开记忆表单,预填上述映射值,评价与照片是空栏;保存 = 创建回忆 + 删计划 +
  取消提醒;取消表单 = 什么都不发生。
- 转化动作统一收口在 `PlanItemRepository.convertToMoment(_:authorID:now:)`(内部调
  `MomentRepository.create` + 删除 + `ReminderScheduler.cancelPlans`),时间线勾选与表单保存共用。

## 五、计划的三态生命周期

| 见面状态 | 计划的形态 | 可做的事 |
|---|---|---|
| planned | 「计划」chip → PlanView 照常(1A 表单) | 加/编/删/勾(勾=纯打勾,可取消勾,不转化) |
| ongoing | chip 消失;已完成项=顶部「行前已备」划线卡;未完成项=待办卡 | 待办:划掉秒转化 / 点卡编辑成回忆 / 左滑删 / 「接下来」组加待办。已备卡:仅左滑删 |
| finished | 已备卡照旧留;未转化项=时间线灰卡「没做成」 | 灰卡点看小地图 / 左滑删;不可再转化 |

## 六、提醒与地图联动

- 提醒取消点:转化时、待办/已备卡删除时、**结束见面时(未完成项的提醒一并取消)**。
  (行前勾掉时提醒已随既有 toggle-done 逻辑取消,开始见面无需再处理。)
- 地图「计划」钉数据源不变(未结束见面的未完成计划项):进行中待办有钉,转化后计划钉消失、
  带地点的回忆出记忆钉;结束后灰卡不出钉(R7 规则自然成立)。`hasActivePlan`/`PlacePruner` 无需改动。
