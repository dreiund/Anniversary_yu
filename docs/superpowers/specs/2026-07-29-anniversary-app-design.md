## 1. 项目概述

为一对情侣（开发者本人与女友）打造的私人 iOS App，用于：记录约会中去过的地点/吃过的店/景点/活动及双方各自的评价与心情；以"自然日"和"约会日/见面"双日历汇总展示；互相记录对方带来的积极/消极事件（附证据）；记录对方的喜好与雷区；记录经期（含预测）与亲密生活；为下次见面编排"日程式"行前计划。

- 使用者：固定两人，现异地恋、将来同城。
- 质量目标：不赶时间，做好为止；预期使用多年。
- 语言：简体中文。

## 3. 技术架构

### 3.1 工程形态

- 单 Xcode 工程，纯 SwiftUI，**零第三方依赖**。仅用系统框架：SwiftUI、Core Data、CloudKit、MapKit、CoreLocation、PhotosUI、LocalAuthentication、UserNotifications。
- 分层：SwiftUI 视图 → 视图模型/仓库层（把 Core Data 包成现代 Swift API，全部业务规则在此层，可单测）→ Core Data 本地库 ⇄ NSPersistentCloudKitContainer 自动镜像 ⇄ CloudKit 私有库共享区。

### 3.2 双人共享模型

- 全 App 只做一次共享配对：根对象 `Couple` 所在自定义 zone 建一个 `CKShare`；创建方生成邀请链接（微信发送），对方接受后成为 readWrite 参与者，此后所有数据双向自动同步。
- 离线优先：本地库永远可读写；断网只影响同步，恢复后自动合并。
- 冲突策略：字段级"最后写入者胜"（`NSMergeByPropertyObjectTrumpMergePolicy`）。双方各自的评分/心情/短评本就是独立字段，互不覆盖。
- Core Data + CloudKit 建模约束从第一天遵守：所有关系 optional、UUID 业务主键、无 unique constraint（用 UUID 应用层去重）。

### 3.3 照片策略

- 选入 App 的照片以原始数据（HEIC/JPEG 原样）存 Binary Data（external storage），CloudKit 侧自动成为 CKAsset 同步。
- 入库时生成两级缩略图（列表小图 / 网格中图）；原图仅在大图浏览时加载。
- 不修改、不占用系统相册；保存到相册是显式操作。
- 本地全量副本随年份增长（数十 GB 量级），两台机型（128GB+）可承受；「本机瘦身」不做，将来有需要再议。

### 3.4 隐私与安全

- 数据只存在两台设备本地 + 两人 iCloud 私有库，无任何第三方服务器。
- App 锁：Face ID / 设备密码，设置中开关。
- 删除等破坏性操作走双确认（systemRed 场景，见 §7）。

## 4. 数据模型

```
Couple 情侣空间（根，CKShare 挂载点）
 ├─ anniversaryDate 在一起的日子
 ├─ Partner ×2
 │    昵称 / 头像 / 主题色 / cloudUserID（绑定 Apple ID）/ tracksCycle（谁的经期被追踪）
 ├─ Meeting 见面
 │    序号（第 n 次，自动可改）/ 标题 / 城市 / 计划或实际起止日期 / 封面照 / 状态（计划中·进行中·已结束）
 │    └─ DateDay 约会日
 │         dayIndex（第 n 天）/ openedAt（开启时刻）/ closedAt（封盘时刻，null=进行中）
 │         └─ Moment 记忆
 │              type（餐厅/景点/活动/住宿/其他）/ title / body 正文（共同记事，两人皆可编辑）
 │              happenedAt（发生时刻）/ → Place（地点，可空）
 │              ├─ Photo ×n（原图 + 缩略图 + 说明 + 排序）
 │              ├─ Evaluation ×2（每人一条：stars 1–5 / mood 表情 / comment 短评）
 │              └─（对方未填时界面显示"TA 还没写 · 提醒一下"）
 │    └─ PlanItem 计划条目（行前计划）
 │         day 日期（可空 = 归"备忘"区）/ time 时间（可空 = 全天）/ title / note 备注
 │         / → Place 或文字地点（可选）/ isDone 完成勾选 / author 添加人 / sortIndex
 ├─ Place 地点
 │    名称 / 地址 / 经纬度 / 类别 / 创建来源
 │    （创建记忆选点时，50 米内同名地点触发"是上次那家吗？"归并建议）
 ├─ DailyMood 每日心情打卡
 │    author / date（自然日）/ mood 表情 / note 可选一句话
 ├─ LedgerEntry 小本本条目（四类共用一套机制）
 │    category：praise 积极 / complaint 消极 / like 喜欢 / trigger 雷区
 │    author（记录人，内容关于对方）/ title 或一句话内容 / reason·detail
 │    ├─ Evidence ×n（截图/照片）
 │    ├─ happenedAt 事发日期（积极/消极必填，喜怒自动取当天）
 │    ├─ → Place 或手选坐标（可选，喜怒一般不填）
 │    └─ visibility（sharedImmediately / privateUntilRevealed）+ revealedAt 公开时刻
 ├─ Cycle 经期周期
 │    startDate / endDate（null=进行中）
 │    predictedStartAtLogging（记录开始时的当期预测值，用于生成偏差档案）
 │    └─ CycleDayLog 逐日记录
 │         date / flow 流量（无·少·中·多·极多）/ pain 疼痛（无·轻·中·重）
 │         / color 颜色（鲜红·暗红·褐·粉·其他）/ note
 └─ IntimacyRecord 亲密记录
      happenedAt / protected 防护（可选）/ note（可选）
      （见面进行中自动关联当前开着的 DateDay）
```

设备本地（不同步，UserDefaults）：App 锁开关、倒计时显示开关、各类提醒开关。

## 5. 核心业务规则

> 以下规则全部实现于仓库层纯函数，配单元测试。

### 5.1 约会日归属与封盘状态机

1. 见面 `Meeting` 手动创建（可提前建"计划中"，其开始日期驱动首页倒计时；到时手动或首条记录触发进入"进行中"）。
2. 见面进行中，新建的 Moment/亲密记录自动归入当前"开着的" `DateDay`（openedAt ≤ now，closedAt == null）；没有开着的约会日时（见面首条记录、或上一天已封盘），新记录自动开启下一个约会日（首条即"第 1 天"）。
3. **封盘**：⊕ 菜单点「🌙 今天到此为止」→ 当前 DateDay 记 closedAt。
4. 保险丝：距上次封盘（或见面开始）超过 18 小时仍未封盘且出现新记录 → 提示"昨天是不是忘了封盘？"，一键补封（补封时刻可手选）。
5. 任何记录可事后移动到同见面的其他约会日；封盘时刻可修改；见面结束时若有未封盘的天，结束动作一并封盘。

### 5.2 双日历投影

- 同一份 Moment 数据两种投影，不存两份：
  - **自然日历**：按 `happenedAt` 的自然日期归日（8.30 0:10 的记录显示在 8 月 30 日）。
  - **约会日视图**：按 DateDay 归属显示（同一条显示在"第 1 天"，即使已过午夜），并标注"约会第 n 天"。
- 足迹·日历页有「自然日 ⇄ 按约会日」开关；日历格子显示：记录圆点、两人当日心情双点、经期浅红底（可关）。

### 5.3 经期预测与偏差

- 预测：取最近 6 个完整周期的间隔均值 → 未来 3 个月开始日；取最近 6 次行经天数均值 → 本次结束日。
- 数据不足 2 个完整周期时用缺省 **28 天周期 / 7 天行经**，界面标注"数据积累中"。
- 每次记录实际开始/结束后，全部预测立即重算。
- **偏差提醒（显示时长规则，用户指定）**：
  - **推迟**：预测开始日次日起，「她」页横幅 + 首页提示行显示"🕐 已推迟 n 天"，**持续到点下「经期开始」的那一刻立即消失**（经期中不留存"晚了 n 天"角标）。仅 App 内展示，不推送。
  - **早来**：记录的开始日早于预测时，状态卡显示"这次早了 n 天"，**仅在记录后 2 小时内显示**，之后消失。
  - **历史档案（非提醒，永久保留）**：历史周期列表逐条徽标"准时 / 推迟 n 天 / 早来 n 天"，依据 `predictedStartAtLogging` 与实际开始日之差（±0 视为准时）。
- 经期开始记录时，两台设备收到轻提醒。
- 校验：结束日不得早于开始日；不做排卵/备孕功能。

### 5.4 小本本可见性

- `privateUntilRevealed` 条目：仅作者可见；对方界面**完全不显示其存在**（无"有隐藏条目"占位，避免猜疑）。
- 作者可随时转公开，`revealedAt` 留痕；公开时对方收到轻通知。
- 列表三栏分段：积极 / 消极 / 喜怒；筛选：TA 记的 / 我记的 / 我的私密箱。喜怒栏内按「❤ 喜欢 / ⚡ 雷区」分组。
- 不做正负数量统计报表（避免比较焦虑，将来想要再加）。

### 5.5 地点归并

- 新建记忆选点（当前定位一键 / 地图搜索 MKLocalSearch / 手动落点）时，若 50 米内存在同名或高相似 Place → 提示"是上次那家 XX 吗？"，确认则关联既有 Place，否则新建。
- Place 聚合出地点档案：来过几次、哪几次见面、两人各自历史均分、全部相关记录。

## 6. 信息架构与页面清单

底部悬浮胶囊 Tab 栏：`我们 · 足迹 · ⊕ · 小本本 · 她`。共约 16 屏 + 1 放射菜单 + 4 快捷弹层。

### 首次启动（仅一次）
创建情侣空间 / 接受邀请 → 填两人昵称·头像·在一起的日子 → 进入主界面。

### ① 我们（首页 · 岁月大字）
- 居中大字标题"在一起 N 天"（SF 紧排 600）+ 纪念日与倒数提示（行动蓝链接）。
- **深色倒计时卡**（圆角卡片，非通栏）：异地平时=「距下次见面 X 天 · 已安排 n 项」（数据源=下一个计划中的见面，可在设置关闭；**点开 = 该见面的行前计划页**）；见面中=「第 n 次见面 · 第 x 天进行中」。
- 今日心情卡（米色圆角卡：两人打卡状态，点击补打）。
- **提醒区**（下半部，分组列表；原"最近的记忆"栏目已删除，照片主场在足迹）：聚合重要通知——TA 新记录待补评、经期状态/已推迟 n 天、TA 公开了互评、忘封盘一键补封等，每行右侧蓝色动作链接；无提醒时显示"一切都好 · 去足迹翻翻回忆"。
- 右上头像 → **设置**：配对管理、在一起的日子、下次见面、Face ID 锁、提醒开关、两人资料。

### ② 足迹（顶部三段切换 = 同一份数据三种看法）
- **见面列表**：每次见面一张封面大卡（第 n 次 · 城市 · 天数）；底部"＋计划下一次见面"；**计划中的见面卡点开 = 行前计划页**。
  - → **见面详情**，顶部切换「时间线 / 路线图 / 计划」：
    - 时间线（照片优先卡片流）：按约会日分组，天数大标题头；每条记忆 = **照片全宽出血（8px 圆角 + 全系统唯一投影）**+ 标题行（类型/时刻小字）+ **两人短评直接露出**（`你 ★★★★★ "…" / 她 ★★★★ "…"`，截两行；对方未填显示"TA 还没写 · 提醒一下"）+ 心情表情对；每天结尾**封盘晚安卡**（深色圆角卡：`2:47 封盘 · 晚安` + 当天统计，非通栏色带）。
    - 路线图：当天/全部地点按时间顺序编号照片钉，行动蓝路径线连接真实路线，按天筛选，播放路径生长动画。
    - **计划（行前计划；见面尚未开始时，从任何入口点开该见面直接落在此页）**：条目按天分组（8.29 / 8.30 / …），iOS 分组清单样式，每条 = 可选时间 + 标题 + 备注 + 可选地点 + 完成勾选（蓝色圆勾）+ 添加人小头像；「备忘」区放不排时间的琐事（白底 chip，完成划线）；**底部毛玻璃统计栏**：左侧"已安排 x 项 · 完成 y 项"，右侧蓝色胶囊「添加日程」。两人皆可增删改（同步）；条目按 日期→时间→sortIndex 排序，无日期条目归备忘区。
- **日历**：月历 + 「自然日 ⇄ 按约会日」开关（见 §5.2）；今天=蓝环标记；点某天 → 当天记录列表。
- **足迹地图**：MapKit 弱化风格底图；圆角矩形照片钉（白描边）；密集自动聚合成墨色小方块（"虹口 · 6"）；顶部类别筛选；点钉 → 地点抽屉 → **地点档案**。

### ③ 中央 ⊕（放射菜单，弹层）
- **记一条记忆**（完整表单）：类型 → 照片多选 → 地点（含归并建议）→ 时刻（自动归入当前约会日）→ 标题 → 正文（共同记事，可选）→ **我的评价：星评 + 心情 + 短评**。保存后对方收到"补上你那一半评价"提醒。
- **记一条互评**（完整表单）：积极/消极 → 标题 → 理由经过 → 证据截图 ×n → 事发日期 → 地点（可跳过）→ 可见性。
- **对方的喜怒**（快捷表单）：❤ 喜欢 / ⚡ 雷区 → 一句话 → 可选佐证·备注·可见性。十秒记完。
- 快捷弹层：今日心情打卡；🌙 封盘（仅见面中出现）；♥ 亲密；🌸 经期开始/结束。

### ④ 小本本
- 三栏分段 [积极 | 消极 | 喜怒] + 筛选（TA 记的/我记的/私密箱），喜怒栏内喜欢/雷区分组（雷区条目带警示色左描边）。
- → 互评/喜怒详情：全文、证据大图、日期地点；私密条目有「公开给 TA」。

### ⑤ 她
- 周期月历（实红经期 / 虚线预测 / ♥ 亲密 / 今日墨环）+ 推迟横幅（按 §5.3 规则）。
- 状态墨卡：经期第 n 天 · 预计结束日（早来时 2 小时内附"这次早了 n 天"）。
- 今日快捷记录：流量/疼痛/颜色三排点选 + 备注。
- 未来三个月预测胶囊；历史周期列表（含偏差徽标）；亲密记录折叠列表（可编辑）。

### 公共二级页（多入口）
- **记忆详情**：照片轮播大图（→ 全屏浏览，可保存相册）、两人评价并排（星+心情+短评全文）、正文、小地图卡 → 地点档案、编辑 / 移动到其他约会日 / 删除。
- **地点档案**：圆形照片头、地址类别、来过 n 次 + 两人均分墨条、历史记录列表、在地图中查看。
- **照片大图浏览**：全屏轮播、捏合缩放、保存到相册。

### 文案纪律
设计小样中的说明性注释（如"（她那半由她自己填）"、"· 新"、"💡 …"）**均不进入真实 UI 文案**。

## 7. 视觉设计系统（Apple 摄影优先风）

依据 `Design_reference/DESIGN-apple.md`，本节为落地令牌。（Mastercard、Slack 方向已废弃，布局决策保留。）核心理念：**照片是主角，UI 隐身**——两人拍的照片全宽出血呈现，界面只用白/米/深三种面 + 唯一行动蓝。

### 7.1 色彩令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| canvas | `#FFFFFF` | 全局底色 |
| parchment | `#F5F5F7` | 米色面：设置/表单页画布、心情卡、评价块、地点统计条 |
| darkCard | `#272729` | 深色卡：倒计时卡、封盘晚安卡、经期状态卡（**一律圆角卡片留边距，禁止通栏色带**） |
| pureBlack | `#000000` | 仅照片大图浏览页画布 |
| actionBlue | `#0066CC` | **唯一交互色**：主按钮、文字链接、选中态描边、今天标记、路线线条、完成勾选 |
| focusBlue | `#0071E3` | 选中 chip 描边、焦点环 |
| skyBlue | `#2997FF` | 深色卡上的链接/强调（行动蓝在深底上看不清时） |
| ink | `#1D1D1F` | 正文/标题（近黑非纯黑） |
| inkMuted | `#86868B` | 次要文字、说明小字 |
| hairline | `#E0E0E0` | 卡片描边、分隔线 |
| systemRed | `#FF3B30` | 危险（删除/解除配对）、雷区标识、推迟提醒 |
| systemGreen | `#34C759` | 成功态（配对已连接、周期"准时"徽标） |
| roseCycle | `#D96450` | 经期专用语义色（日历标记、流量/疼痛点选） |

原则：可点的东西只有一种颜色（行动蓝）；深色卡是内容强调面不是品牌色；除语义色外不引入任何第三色、任何渐变。

### 7.2 形状·字体·深度

- 圆角：8（照片/图钉/utility 钮）· 12–14（卡片、分组列表）· 18（大卡）· 药丸（主按钮、chip、搜索框）。**深色内容一律做成圆角卡片（darkCard），左右留 16pt 边距，绝不通栏横穿屏幕**（用户明确修正）。
- 字体：系统 SF Pro Display（≥20pt 标题，600 字重 + 负字距"Apple 紧排"）+ SF Pro Text（正文 17pt/400，行高约 1.47）+ 苹方。字重阶梯 300/400/600，**500 缺席**；300 只用于极少数"轻盈"场景。
- 深度：默认平面 + 1px hairline；**全系统唯一投影** `rgba(0,0,0,0.22) 3 5 30` 只给"落在页面上的照片"，卡片按钮文字一律无影；Tab 栏与计划页统计栏用**毛玻璃**（parchment 85% + backdrop blur）。
- 触控目标 ≥ 44pt；全系统按压微交互 = `scale(0.95)`。

### 7.3 按钮与文案纪律（用户修正 ③）

- 按钮文案：**单行短语 ≤ 6 字、不含 emoji、永不换行**。⊕ 菜单七项一律两字：记忆 / 互评 / 喜怒 / 心情 / 亲密 / 经期 / 封盘。
- 辅助说明不进按钮，放按钮下方小字（如"公开时刻会记录"）。
- emoji 只作为**内容数据**出现：心情打卡、记录里的表情、日历标记；不出现在任何按钮、Tab、章节标题里。
- 设计小样中的注释性文字（"她还没打卡"属于真实状态文案，保留；"（她那半由她自己填）"之类说明属于注释，不进 UI）。

### 7.4 组件对应

| 组件 | Apple 令牌落地 |
|---|---|
| 主按钮 / 添加日程 / 公开给 TA | 行动蓝实心药丸，白字；次按钮 = 蓝描边幽灵药丸 |
| 分段切换（时间线/路线/计划 等） | 白底胶囊 chip，选中 = focusBlue 1.5px 描边 + 蓝字 |
| Tab 栏 | 毛玻璃通底栏 + hairline 顶线；激活项蓝字；中央 ⊕ 行动蓝圆钮 |
| 倒计时卡 / 封盘晚安卡 / 经期状态卡 | darkCard 圆角卡片（内文白 + skyBlue 链接 + `#CCCCCC` 次要字） |
| 首页提醒区 / 设置 / 表单 / 小本本 | iOS 分组列表（白组卡 + hairline 内分隔），动作为右侧蓝色链接 |
| 记忆呈现（时间线/详情） | 照片全宽出血 8px 圆角 + 唯一投影；文字退到照片下方；评价块 parchment 圆角卡 |
| 计划页 | iOS 分组清单 + 蓝色圆勾 + 底部毛玻璃统计栏（左统计右蓝色胶囊） |
| 地图 | 弱化底图；圆角矩形照片钉（白描边）；聚合 = 墨色小方块 chip；路线 = 行动蓝线；抽屉白卡毛玻璃 |
| 经期月历 | roseCycle 实心经期日、虚线预测、今天 = 蓝环；历史徽标用文字色（绿准时/红推迟/蓝早来） |
| 雷区标识 | systemRed 左侧细竖线 |
| 照片大图 | 纯黑画布 + 半透明灰圆钮（`rgba(210,210,215,0.64)`） |

### 7.5 动画（实现时调用 swiftui-motion / swiftui-graphics skills）

| 场景 | 设计 |
|---|---|
| 封盘仪式（重点打磨） | 当天记录轻收拢 → 深色晚安卡落下入位（弹簧）+ 轻触感震动 |
| 照片→详情转场 | iOS 18 zoom 转场（matchedTransitionSource），照片原地放大到全屏 |
| 路径线生长 | 路线图播放：行动蓝路径沿真实路线 trim 0→1 生长 |
| 大数字 | `contentTransition(.numericText())` 滚动（412 天、倒计时） |
| ⊕ 菜单 | 弹簧放射展开，子项 stagger |
| 按压 | 全系统按钮 `scale(0.95)`（Apple 签名微交互） |
| 计划勾选 | 蓝色圆勾弹入 + 条目轻划线 |
| 微交互 | 心情 emoji 选中弹跳（PhaseAnimator）、星星点亮波浪、列表 scrollTransition 轻淡入、月历翻页平移 |
| 无障碍 | 全部尊重"减弱动态效果"系统设置 |
| 性能 | 列表只用缩略图；动画仅 transform/opacity |

## 9. 错误处理与边界

- **同步**：离线完全可用；iCloud 账号未登录/容量满 → 顶部横幅"同步已暂停"，本地照常；恢复自动合并。
- **配对**：邀请链接失效/对方未登录 iCloud → 明确文案 + 重发邀请；设置页常驻配对状态。
- **权限**：相册/定位被拒 → 引导设置；定位拒绝时地图手动选点照常可用。
- **地图**：MapKit（境内自动高德底图无偏移）；搜索 MKLocalSearch。
- **时间**：时间戳 + 时区一并存储，跨时区显示正确；封盘遗忘走 §5.1 保险丝。
- **删除**：双确认；不做回收站。
- **经期**：结束≥开始校验；样本不足按 §5.3 缺省。
- **照片**：原图加载失败以缩略图兜底并可重试。

## 10. 测试策略

- **单元测试（重点）**：约会日归属/封盘状态机、双日历投影、经期预测与偏差计算（含 28/7 缺省、推迟/早来边界、2 小时窗口）、小本本可见性过滤、地点归并判定、计划条目排序（日期→时间→sortIndex，无日期归备忘）。
- **仓库层**：内存 Core Data 栈跑 CRUD 与关系完整性。
- **同步**：两台真机 + 两个 Apple ID 手动清单：配对、双向同步、离线恢复、同条并发编辑、照片大文件、共享接受流程。
- **UI**：关键流程 smoke（新建记忆、封盘、经期开始）。
- **Beta**：两位使用者即 TestFlight 测试员。

## 11. 实现阶段

每阶段结束都是可用状态：

- **P0 地基**：Xcode 工程；设计系统组件库（色彩/字体/胶囊按钮/卡片/悬浮 Tab 栏/eyebrow）；完整 Core Data 模型 + 本地存储；（前置：验证最新 SwiftData 共享支持情况，定最终存储实现）
- **P1 记忆核心**：见面/约会日/记忆 CRUD + 封盘状态机 + 见面详情时间线 + 行前计划页 + 首页（单机可用）
- **P2 双人化**：CloudKit 同步 + CKShare 配对流程 + TestFlight 分发 + 对方补评 + 通知（她加入）
- **P3 视图**：日历双投影 + 足迹地图（照片圆钉/聚合/筛选）+ 地点档案 + 见面路线图

P2 靠前因为"她能参与"是这个 App 的灵魂；P4/P5 相对独立可换序。
