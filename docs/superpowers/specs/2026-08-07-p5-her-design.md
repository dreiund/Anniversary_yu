## 决策记录（用户逐题选定）

| 议题 | 决定 |
|---|---|
| 历史周期补录 | 支持（统计页「＋补录一段」，起止两个日期，无当时预测值，徽标「—」） |

## 一、页面结构（自上而下，到日历为止）

1. **导航标题**：`记录·她`（inline）。
2. **推迟横幅**（条件显示）：浅粉底玫红字 `🕐 已推迟 n 天`，无动作链接；
   显示与消失严格按主 spec §5.3（预测开始日次日起，点下「经期开始」立即消失；不推送）。
3. **粉色状态小卡**（双态，替代旧「状态墨卡」与「未来三个月预测胶囊」，浅粉底 `#FDF1EF`）：
   - 经期中：左 `经期第 n 天`（玫红粗体）· 右小字 `预计 M月d日 结束`；
     早来时左侧下方附小字 `这次早了 n 天`（仅记录后 2 小时内，见 §5）。
   - 非经期：左 `距下次预计还有 n 天` · 右小字 `M月d日`。
   - 一条周期都没有时：单行 `还没有经期记录 · 点日历上的日期开始记`。
4. **周期月历**（主体，白卡 hairline 描边）：
   - 顶行：左 `回今天`（行动蓝小字，一键回当月）· 中 `‹ yyyy 年 M 月 ›` · 右 `统计`（行动蓝小字，进统计页；**纯文字不用图标/emoji**）。
   - 整月网格（周一起始，星期行 一二三四五六日），**左右滑动切换月份**。
   - 天格状态：**经期天=浅粉底 `#F8E3DF` + 玫红数字**（实红改浅红：为让四点配色可辨）；
     预测天=玫红虚线描边空心；今天=墨环；其余白底。
   - **四点行**（数字正下方，固定顺序，缺项不占位）：
     ① 疼痛点 ② 流量点 ③ 颜色点——红 `dsRed` / 黄 `dsOrange` / 绿 `dsGreen` 对应重/中/轻档；
     ④ 亲密点——行动蓝，**实心=有措施，空心=无措施**；同一天多条亲密记录时，只要有一条无措施就显示空心（风险信号优先）。
   - 图例小字两行：`左右滑动换月 · 浅红=经期 · 虚线=预测 · 墨环=今天` 与
     `点：疼痛/流量/颜色（红黄绿=重中轻）· 蓝点亲密（实心有措施）`；预测用缺省参数时（完整周期<2）第一行追加 `· 数据积累中`。
5. 页面到此为止。今日记录卡、历史周期列表、亲密折叠列表**全部删除**——查看与记录一律点日历日期。

## 二、记录卡（点任意日期弹出的 sheet）

顶部分段开关：`生理期 | 亲密活动`（⊕ 面板进入时按入口预选段）。

### 生理期段（按所点日期 D 的处境显示）

1. **D 在某段经期内**（含进行中）：标 `经期第 n 天`；三排点选（点选即存、再点取消、每排单选可空）+ `备注（可选）` 输入；若该段未结束且 D ≥ 开始日，底部给玫红描边按钮 `这天经期结束`。
2. **D 不在任何经期、且无进行中经期**：只给主按钮 `这天经期开始` ——新建周期（开始=D），同时把**当时的预测开始日**写入 `predictedStartAtLogging`（无预测可写时留空）。
3. **D 不在经期、但有进行中经期且其开始日早于 D**：给 `这天经期结束`，把进行中段收尾于 D；附小字 `经期从 M月d日 开始`。
4. **D 早于进行中段的开始日、且不在任何段**：无动作，提示 `要补过去的经期，去统计页「补录一段」`。
5. **D 是未来日期**：无任何记录动作，只显示 `未来的日子只能看预测`。

### 亲密活动段

- Toggle `有措施`（**默认开**）+ `备注（可选）` + `保存`。
- 时刻落值：D=今天 → 现在时刻；D=过去 → 当天 12:00（只关心日期）。
- 归属：D=今天且有见面进行中 → 自动挂当前开着的约会日（主 spec §4 规则）；其余只归 couple。
- 当天已有记录：列出（时刻+措施+备注），可改可删（删除确认 `删除这条记录？`）。共管：无作者概念，两人都可记/改/删（模型无作者字段，天然如此）。

### 校验（弹卡层拦截）

- 结束 ≥ 开始（主 spec 既定）。
- 新开始日 / 补录段 / 修改起止后的区间，不得与既有周期重叠 → alert `和 M月d日 – M月d日 那段重叠了`，拒绝保存。

## 三、档位与存储锁值（不可再改）

| 字段 | 0 | 1（绿·轻） | 2（黄·中） | 3（红·重） |
|---|---|---|---|---|
| painRaw 疼痛 | 未记 | 不痛 | 轻微 | 很痛 |
| flowRaw 流量 | 未记 | 少 | 中 | 多 |
| colorRaw 颜色 | 未记 | 褐色 | 暗红 | 鲜红 |

- `CDCycleDayLog`：每（周期,自然日）至多一条，upsert；day 存当天 00:00。
- `CDIntimacyRecord.protectionUsed`：恒非空布尔（开关语义）。
- `CDCycle`：startDate 必填；endDate 空=进行中；predictedStartAtLogging 空=补录/当时无预测。

## 四、统计页（月历右上「统计」推入）

- 顶部分段 `月 | 年` + `‹ ›` 翻范围（月：`yyyy 年 M 月`；年：`yyyy 年`）。
- 三张数字卡：
  - **疼痛率**（浅粉卡）：范围内记过疼痛的经期天中，档 ≥ 轻微 的占比；无数据显 `—`。
  - **准时率**（浅粉卡）：范围内**结束**且有当时预测值的周期中，|实际开始−预测开始| ≤ 2 天的占比；无样本显 `—`。（两种口径并存：下方列表徽标严格 ±0 判「准时」——主 spec 既定；准时率卡取 ±2 容差作为概率性指标）
  - **亲密**（淡蓝卡）：范围内亲密记录条数，`n 次`。
- **历史周期列表**（统计页下半部；主页删除后安置于此）：
  - 行：`M月d – M月d`（进行中段右侧为 `进行中`）+ 偏差徽标 `准时`（绿）/ `推迟 n 天`（橙）/ `早来 n 天`（橙）/ `—`（灰，补录），判定依据 predictedStartAtLogging（主 spec §5.3）。
  - 点行 → `修改起止` sheet（两个日期选择器，走 §二 重叠校验）。
  - 行左滑删除（复用 SwipeDeleteRow）→ 确认 `删除这段经期？` / `这段的每日记录会一并删除。`
  - 底部 `＋ 补录一段`：起止两个日期选择器，保存为过去周期。
- 任何写操作后全部预测立即重算（主 spec 既定）。

## 五、预测引擎（CyclePredictor 纯函数，TDD 全矩阵）

- 输入：全部周期（含进行中）。完整周期按开始日排序：相邻开始日间隔取最近 ≤6 个均值=周期长度；行经天数取最近 ≤6 个完整段的 `结束−开始+1` 均值。
- 完整周期 < 2 → 缺省 28 天 / 7 天，输出「数据积累中」标志。
- 产出：未来 3 个月预测开始日（各带行经天数，月历画虚线）、进行中段预计结束日、下一次预测开始日（粉卡/推迟横幅用）。
- 推迟 n 天 = 今天 − 预测开始日（今天>预测开始日 且 无进行中段时才显示）。
- **早来附注的 2 小时窗**：已部署的 CDCycle 无记录时刻字段——用**本机** UserDefaults 存「最近一次点经期开始的时刻」，纯展示、不同步，两端各自计时（可接受的偏差）。

## 六、通知与跨页接线

- **通知**：任一端记录「经期开始」→ 对方设备横幅 `TA 记录了经期开始`（HistoryMonitor 监听 CDCycle 插入，沿 P4 小本本管线）；**只对 endDate 为空的插入触发**——补录一段保存时起止俱全，不惊动对方；改起止/删段也不通知。设置页开关 `经期开始提醒` 默认开。推迟/早来仅 App 内展示，不推送（主 spec 既定）。
- **底栏**：`她` tab 解禁为正式页（AppTab.her）。
- **⊕ 面板**：补 `亲密`、`经期` 两格凑满 2×3（主 spec 既定）——点开=打开**今天**的记录卡并预选对应段；未选归属时先走首次选人。
- **首页提醒区**：推迟时一行 `🕐 已推迟 n 天`、经期中一行 `经期第 n 天`，动作链接 `去看看` → 她页；其余情况无行。
- **足迹·日历**：经期天浅粉底（数据同源）；设置页开关 `足迹日历经期底色` 默认开（主 spec「可关」落地）。
- **设置页**新增三行：`经期归属`（显示被追踪人昵称，点开重选）、`经期开始提醒`、`足迹日历经期底色`。

## 七、首次选人（tracksCycle 守门）

- 进她页 / ⊕ 点亲密或经期时，若两位伴侣都无 `tracksCycle=true` → 弹选人页：
  标题 `记录谁的经期？`、副题 `只问一次，设置里随时可改`、两张头像名字卡选一 + `确定`。
- 落值：所选伴侣 tracksCycle=true（另一位置 false）；改归属同一 UI，从设置进入；周期数据挂 couple，不随归属改动。

## 八、测试与种子
